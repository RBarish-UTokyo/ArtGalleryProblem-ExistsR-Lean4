# Section 5 construction — index

The explicit construction is split into several files (to keep each document small):

* [`01_overview.md`](01_overview.md) — notation, list of units, deviations from the paper
* [`02_main_area.md`](02_main_area.md) — base line, pockets (all vertices), `one`-spikes, hexagon, shifts `d_i`
* [`03_witness_tools.md`](03_witness_tools.md) — the proof tools (cones, rooms, stationary guards, counting)
* [`04_corridor.md`](04_corridor.md) — corridors: every vertex as a formula, exactness of copies
* [`05_gadgets.md`](05_gadgets.md) — gadget templates (inversion, ≥-add, ≤-add, orientation), topological constraint
* [`06_assembly.md`](06_assembly.md) — boundary order, guard count `g = 46n + 16k_add + 5k_inv`, canonical guards, denominators, `n = 0`
* [`07_template_vertices.md`](07_template_vertices.md) — exact vertex lists of the four gadget templates
* [`08_proof_plan.md`](08_proof_plan.md) — the structure of the formal proof and its Lean files
* [`10_template_certificates.md`](10_template_certificates.md) — the template facts proved by certified computation
